# Getting help

- **Docs and guides:** [smallpict.app/docs](https://smallpict.app/docs)
- **API reference:** [smallpict.app/api-reference](https://smallpict.app/api-reference)
- **Account, billing or API keys:** [support@smallpict.app](mailto:support@smallpict.app) or the [dashboard](https://smallpict.app/dashboard)
- **Bug in an SDK or the plugin:** open an issue in that repository
- **Security issue:** see [SECURITY.md](SECURITY.md)

GitHub issues are for bugs and feature requests. For account questions please email us, so your account details stay private.
