# Security Policy

Thank you for helping keep SmallPict and its users safe.

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Email **[security@smallpict.app](mailto:security@smallpict.app)** with:

- the affected repository, package or endpoint, and the version
- steps to reproduce, or a proof of concept
- the impact you expect

We will confirm that we received your report and keep you updated until the issue is fixed. Please give us a reasonable time to release a fix before you disclose it publicly.

## Supported versions

Security fixes go into the latest release of each SDK, the WordPress plugin and the hosted API. Please upgrade to the latest version before reporting.

## Handling credentials

Never include real API keys, secret keys or customer images in issues, pull requests or logs. If a key was exposed, rotate it in the [dashboard](https://smallpict.app/dashboard) right away.
