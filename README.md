# smallPict/.github

Organization-wide files for [github.com/smallPict](https://github.com/smallPict).

| Path | What it does |
|---|---|
| `profile/README.md` | The public overview shown on the organization page |
| `profile/assets/` | Banner images for the overview (dark and light) |
| `assets/social-preview.png` | 1280×640 image to upload as a repository social preview |
| `SECURITY.md`, `CONTRIBUTING.md`, `SUPPORT.md`, `CODE_OF_CONDUCT.md` | Defaults for every repository that does not have its own copy |
| `.github/ISSUE_TEMPLATE/`, `.github/pull_request_template.md` | Default issue forms and pull request template |
